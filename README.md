# React + TailwindCSS 테스트 앱

React와 TailwindCSS를 사용한 간단한 카운터 앱입니다.

## 기능

- 카운터 증가/감소/초기화
- TailwindCSS를 사용한 현대적인 UI
- 반응형 디자인

## 실행 방법

### 개발 서버 시작

```bash
npm start
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 앱을 확인할 수 있습니다.

### 빌드

```bash
npm run build
```

프로덕션용으로 앱을 빌드합니다.

## 기술 스택

- React 19.1.1
- TailwindCSS 3.4.0
- PostCSS & Autoprefixer
